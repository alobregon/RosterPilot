# Draft Companion 100-Mock Behavior Study — 2026-09-02

## Goal

Exercise the same on-clock decision path used by the Draft Companion UI across many plausible draft rooms before tuning the engine further.

This is a **behavioral stress test**, not an independent proof that the recommendation model is optimal. Opponent selections are generated by RosterPilot's own simulator, so results that depend on opponent behavior must be interpreted accordingly.

## Input and setup

The study used the user-provided `FantasyPros_2026_Draft_ALL_Rankings(5).csv` as the authoritative ranking baseline. The uploaded file contained 428 rows. A temporary normalized top-280 subset was used only to execute the experiment; it included enough players to complete a 160-pick draft plus the relevant late K/DST pool. The raw provider export and temporary normalized fixture are not retained in the repository after the study.

League setup:

```text
10 teams
Half-PPR
User slot #7
1 QB / 2 RB / 3 WR / 1 TE / 1 FLEX
1 DST / 1 K / 6 bench
Balanced strategy
No Favorites / My Guys
```

The experiment ran 100 stochastic mocks plus one neutral control:

| Scenario | Runs |
| --- | ---: |
| Normal room + historical managers | 40 |
| RB rush + historical managers | 20 |
| WR rush + historical managers | 20 |
| QB rush + historical managers | 10 |
| TE rush + historical managers | 10 |
| Neutral rank-order, history off | 1 control |

Historical manager assignments were rotated between runs and every stochastic mock received a different deterministic seed. Repeating a neutral history-off rank-order room many times would produce the same draft, so it was retained as a single control rather than counted as stochastic evidence.

## Important harness correction

The existing full-draft helper in `lib/simulation.ts` auto-selects the user's picks through the older base `recommendPlayers()` function. That does not exercise all current live-draft behavior.

The study therefore introduced a reusable research helper:

```text
apps/draft-companion/lib/mock-research.ts
```

`simulateDecisionEngineMock()` uses:

```text
recommendForCurrentPick()
```

for the user and `simulateNextOpponentPick()` for opponents. This means the study includes the same on-clock layers currently used by the UI:

- deterministic ranking / roster / tier scoring;
- calibrated chance-back probability where supported;
- bounded Purple League history adjustment;
- bounded offseason / injury context adjustment;
- mandatory roster-completion constraints.

## Headline results

All **100/100 stochastic mocks completed**, all **100/100 produced a legal starting roster**, and all **100 rosters were unique**.

Average final roster:

| Position | Average |
| --- | ---: |
| QB | 1.65 |
| RB | 4.89 |
| WR | 6.44 |
| TE | 1.02 |
| DST | 1.00 |
| K | 1.00 |

Roster-shape flags:

- 61/100 drafts selected at least two QBs;
- 2/100 selected at least two TEs;
- 12/100 selected six or more RBs;
- 45/100 selected seven or more WRs.

The QB2 frequency is the clearest roster-construction tuning candidate from this study. TE depth is already well controlled. WR depth is aggressive but not automatically wrong in a three-WR plus FLEX format and should be judged in the manual golden mock before changing weights.

## Rank discipline

Late mandatory DST/K selections create very large apparent ECR reaches, so K and DST were excluded from the skill-player reach analysis.

Across QB/RB/WR/TE selections:

| Metric | Result |
| --- | ---: |
| Average rank reach | **-2.34** |
| Average positive reach | 2.55 |
| 90th percentile positive reach | 6 |
| Maximum positive reach | 10 |
| Reaches >5 ranks | 67 |
| Reaches >10 ranks | **0** |

Negative average reach means RosterPilot generally selected a player ranked **better** than the current draft slot. Most importantly, the engine never reached more than ten ECR spots for a skill player in the 100 stochastic mocks.

This supports the current rank/tier guardrails. The large raw reaches seen in an initial unfiltered report were late legal-roster DST/K selections rather than evidence that skill-player context was overruling the rankings.

## Chance-back behavior

The selected candidate's average calibrated chance of surviving to the following user pick was 51.9%. A total of 463 selections had a displayed chance-back of at least 65%.

A high chance-back alone is not an error: the player may still be clearly stronger than the alternatives. The research harness therefore flagged a stricter timing conflict only when:

1. the selected player had at least a 65% chance to return;
2. another candidate had at most a 35% chance to return; and
3. that alternative was within two raw recommendation-score points of the selected player.

Only **3 / 1,600 decisions (0.2%)** met that definition:

- Jayden Daniels over Quinshon Judkins;
- Joe Burrow over Terry McLaurin;
- Joe Burrow over Davante Adams.

All three occurred in RB-rush rooms. This suggests the chance-back/timing layer is behaving conservatively rather than routinely wasting return probability.

| Position | Average first selection |
| --- | ---: |
| WR | 1.68 |
| RB | 2.52 |
| TE | 4.14 |
| QB | 4.46 |

The room profiles moved timing in the expected direction. For example, the first QB moved to Round 6.7 in QB-rush rooms as opponents depleted the position, and the first RB moved to Round 4.8 in RB-rush rooms as the user often pivoted away from a depleted RB market.

The aggregate QB timing itself is not enough to diagnose an error — elite QB value can legitimately fall in a 10-team league. The stronger signal is the **61% QB2 rate**, including a second quarterback in Round 14 of the neutral control.

## Conclusions and next actions

The study supports several parts of the current architecture:

1. **Roster legality is robust.** Every stochastic draft completed legally.
2. **Skill-player rank discipline is strong.** No QB/RB/WR/TE selection reached more than ten ECR spots, and the average selection beat the current draft slot by 2.34 ranks.
3. **Chance-back timing looks healthy.** Strict near-equal timing conflicts occurred in only 0.2% of decisions.
4. **Context is bounded in the intended way.** It changed close decisions frequently but never caused a tier drop in the study.
5. **Backup QB is the clearest tuning target.** Sixty-one percent of drafts carried QB2 in a one-QB league.
6. **Player concentration should be monitored as freshness changes.** MarShawn Lloyd's 97% rate is a useful warning that current opportunity news plus stale/later market ADP can make one player nearly universal.
7. **A manual golden mock is still necessary.** Aggregate metrics cannot tell us whether individual explanations and tradeoffs feel intelligent.

Recommended next sequence:

```text
1. Add / test a bounded backup-QB suppression rule.
2. Re-run this 100-mock study with the same seeds and compare deltas.
3. Perform one manual golden mock from slot #7 with the current rankings.
4. Inspect representative context flips and WR-depth decisions before tuning context or roster weights.
```

The research harness is intentionally reusable; the one-off provider-data fixture and heavy experiment test are not retained in normal CI.
