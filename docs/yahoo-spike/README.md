# Yahoo Gate 0 Spike

Goal: prove or disprove the currently supported Yahoo Fantasy integration required for RosterPilot.

## FGM-001

Connect a Yahoo test account and retrieve fantasy football leagues, selected team, roster, and league settings.

## FGM-002

Using a disposable league, determine and document currently supported roster-write capability for:

- lineup changes
- add/drop
- waiver claims
- FAAB waiver claims

Document endpoint/method, authorization, payload, responses, verification strategy, provider documentation, and provider terms.

Do not make unsupported browser automation a hidden production dependency.
